
# Mirow & Co. — Verificador de Relatório

Este repositório contém uma solução para o exercício técnico da Mirow & Co. AI Division.

O projeto utiliza Python e Pandas para analisar dados de pedidos, calcular indicadores e verificar a consistência dos valores apresentados em um relatório gerado por um agente de IA.

Também inclui testes automatizados com Pytest para validar os cálculos e o funcionamento do verificador.

## Estrutura do projeto

- `data/`: arquivo CSV com os dados dos pedidos.
- `src/`: código-fonte da análise de dados e da verificação do relatório.
- `test/`: testes automatizados do projeto.

## Tecnologias utilizadas

- Python
- Pandas
- Pytest
